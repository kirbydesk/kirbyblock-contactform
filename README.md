# kirbyblock-contactform

Contact form block for the Kirby Pagewizard: fixed fields (name, e-mail, phone, company, subject, message), sortable, shown or required per block, half or full width; consent with a link to the privacy page; sent by SMTP only (set up in the Project Wizard › Blocks › Contact form › Sending, the password stored encrypted with the key in site/config/contactform.key); an optional confirmation to the sender; invisible spam protection (honeypot and minimum time). Nothing is stored.
